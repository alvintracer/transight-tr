# Lint Prompt

```text
lint 해줘.

다음을 점검해줘.

1. raw 원본이 수정되었거나 wiki 영역에 섞여 있지 않은가?
2. 중요한 wiki 문서가 index.md에 누락되어 있지 않은가?
3. 중요한 작업이 log.md에 기록되어 있지 않은가?
4. 저장의 5가지 필터를 통과하지 못한 일회성 정보가 wiki에 저장되어 있지 않은가?
5. 민감정보, API key, 비밀번호, 토큰, 고객 개인정보, 수사자료, 비공개 계약 원문, 민감한 지갑주소/트랜잭션 사건 자료가 저장되어 있지 않은가?
6. 출처 없는 결정이나 오래된 규칙이 active 상태로 남아 있지 않은가?
7. superseded 되어야 할 문서가 계속 active로 남아 있지 않은가?
8. 다음 에이전트가 봐야 할 운영 문서가 빠져 있지 않은가?

문제가 있으면 파일별로 수정 제안을 정리해줘.
```
