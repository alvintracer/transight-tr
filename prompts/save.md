# Save Prompt

```text
save 해줘.

저장하기 전에 START_HERE.md, CLAUDE.md, AGENTS.md의 저장 규칙을 확인하고, 저장의 5가지 필터를 적용해줘.

아래 중 하나라도 만족하는 정보만 wiki에 저장해줘.

1. 향후 실무에 반복해서 재사용될 데이터인가?
2. 다른 에이전트나 동료가 프로젝트를 이어받기 위해 반드시 읽어야 하는가?
3. 의사결정의 근거와 결정권자를 나중에 추적할 필요가 있는가?
4. 실패한 방식이라 다시 시도하면 안 되는 리스크 정보인가?
5. 팀 전체가 맞추어야 하는 공통 규칙이나 디자인 가이드인가?

일회성 답변, 사소한 중간 생각, 검증되지 않은 추측은 wiki에 저장하지 마.
API key, 비밀번호, 토큰, 고객 개인정보, 수사 관련 원문, 비공개 계약 원문, 민감한 지갑주소/트랜잭션 사건 자료도 wiki에 저장하지 마.

저장할 가치가 있으면 적절한 wiki 카테고리를 판단해서 문서를 만들고, index.md와 log.md도 갱신해줘.
저장할 가치가 없으면 저장하지 말고 그 이유를 짧게 설명해줘.
```
