이 전략이 극도로 강력한 이유

1. Warm Cross-sell

Cold Start가 아니다. 이미 8개 기관이 고객. 기존 제품 위에 기능 하나 더 얹는 것.

2. TR 원가 = 합리적

TR은 미끼, KYT가 본체. TR이 KYT lock-in을 강화. 프린터(TR) 싸게 팔고 잉크(KYT)로 번다.

3. CODE 비공격적 대체

CODE와 정면 경쟁 선언 ❌. 금융기관 측 진입점만 장악. CODE 볼륨은 오히려 증가.

4. 비대칭 브릿지 = 필수

금융기관은 보안 기준을 낮추지 않는다. mTLS/VPN/전용선 = TTR만 가능한 영역.

5. 두나무 = 리스크이자 기회

KYT 파트너십이라는 협상 채널. 금융기관 확보 후 거절보다 수용이 합리적인 구조 형성.
