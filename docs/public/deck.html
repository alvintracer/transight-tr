Bonanza TTR

CodeVASP-compatible Travel Rule Gateway for financial institutions, VASPs, and overseas counterparties.

Core Model

  1. Bonanza operates the VASP Public Key Directory.
  2. Originators encrypt Travel Rule payloads for the beneficiary public key.
  3. Bonanza relays encrypted payloads and manages metadata, status, and audit evidence.
  4. Financial institutions connect through IDC channels such as mTLS, VPN/IPsec, or leased line.
  5. OwnerCheck provides Identical Account Owner Verification as a Bonanza extension.

Active And Disabled Rails

Rail Status Policy
Bonanza Relay Active Default route
CodeVASP-Compatible Active Compatibility model
GTR, Sumsub, VerifyVASP Disabled Future optional rails only

Primary APIs

/vasp-registry, /transfer-auth, /owner-check, /health
